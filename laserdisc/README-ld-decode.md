# laserdisc — FM RF archival samples (LaserDisc)

This is a mix of `.lds` / `.ldf` FM RF archival samples linked to bug reports
and standard test data (such as colour bars and the Jason and the Argonauts
PAL test cards).

These FLAC-compressed RF archives decode to 4fsc TBC data via ld-decode.
Intended for non-infringing / fair-use research to support the video-decode
toolchain.

See the top-level `README.md` for the full RF → decode → TBC → export guide.
